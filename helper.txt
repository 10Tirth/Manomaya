# Manomaya 2026 – End‑to‑End Build & Deployment Guide

## Overview
We built a production‑grade, single‑page React site for **Manomaya 2026** – a college mental‑health festival. The site:
- Shows hero, marquee, about, journey, activities, wellness widgets, support, FAQ, final CTA, footer.
- Adds **Schedule** (day‑by‑day timeline) and **Stalls** (food/shop marketplace) making it a superset of the reference site.
- Provides a native HTML `<dialog>` registration flow that posts to a Google Sheets‑backed Apps Script backend.
- Stores only registration IDs locally (no personal data).
- Is fully responsive, accessible, and respects reduced‑motion preferences.
- Uses Vite 6 + React 18, Tailwind CSS 4, framer‑motion, three‑js + react‑three‑fiber/drei.

## Deploy Instructions (choose one)
### Netlify (quickest)
```bash
npm run build            # generates ./dist
npm i -g netlify-cli    # if not installed
netlify deploy --dir=dist --prod
```
- Connect the repo in the Netlify dashboard for automatic builds.

### Vercel
```bash
npm run build
npx vercel --prod   # requires Vercel CLI login
```
- Or link the repo in the Vercel UI and select the Vite preset.

### GitHub Pages (via workflow)
```bash
git push            # triggers .github/workflows/deploy-pages.yml
```
- After the workflow finishes, the site is available at `https://<USERNAME>.github.io/Manomaya/`.

## Verifying the Registration Flow
1. Open the live site.
2. Click any **Register** button – the dialog opens.
3. Fill required fields (Name, Email, Phone, College, Course, Year, Consent) and select one or more activities.
4. Submit – you’ll see a success screen with a registration ID and a download button for an `.ics` calendar file.
5. Check your Google Sheet – a new row appears for each selected activity (timestamp, registration ID, activity details, user data).
